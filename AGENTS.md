# Agent instructions

## Milestone execution

For an approved milestone, complete the entire scoped milestone in its existing branch and draft pull request without pausing after internal implementation slices.

Use bounded commits internally, but do not request direction or provide interim handoffs for each slice. Continue through implementation, automated tests, documentation, CI remediation, and pull-request readiness.

Stop only when:

- a material product, security, legal, licensing, or architecture decision is required;
- required manual acceptance must be performed by the user; or
- an external dependency prevents safe progress.

Do not merge a pull request without explicit user approval.
